PRIVACY POLICY

Personal Health Dashboard

This application is for the personal use of Vitalii Matiunin only. It is not a public service and is not offered to third parties.

Data accessed

The application accesses the following data from connected providers (WHOOP, YAZIO, and similar personal-health services):

  • Recovery, heart rate variability (HRV), and resting heart rate
  • Sleep duration, stages, and performance
  • Workouts, strain, and activity sessions
  • Body measurements (weight, height)
  • Nutrition diary, caloric intake, and macronutrients

Storage

Data is stored locally on infrastructure controlled by the user (a private SQLite database). The data is not uploaded to any third-party server. Encrypted weekly backups may be sent to the user's own private Telegram account.

Sharing

No data is shared with any third party. The application does not have a public API and does not expose data to any external service.

Retention

Data is retained until the user manually deletes it. The user can revoke OAuth access at any time through the provider's dashboard (e.g., the WHOOP developer portal).
